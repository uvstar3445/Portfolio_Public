# Yuvraj Nag — Portfolio

Personal portfolio for my work in data analytics, business intelligence, technical systems, infrastructure, embedded systems, and engineering design.

The site is intentionally lightweight and built as a static website so it is fast, easy to maintain, and straightforward to host with GitHub Pages.

- **Power BI Dashboards** — Power BI, Power Query, DAX, data modelling, KPI design, and dashboard development
- **Home Virtualization Server** — Proxmox VE, Ubuntu Linux, Docker, networking, storage, DNS/VPN, and troubleshooting
- **AES-128 FPGA Coprocessor** — C, Verilog, FPGA integration, memory-mapped I/O, and hardware-software communication
- **Cyanobacteria Rover Design** — SolidWorks, systems design, material selection, lifecycle costing, and engineering economics

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
